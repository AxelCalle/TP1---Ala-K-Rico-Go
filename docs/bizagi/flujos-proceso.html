Cliente Sistema Administrador Repartidor

Ciclo de vida completo del pedido. El cliente selecciona productos y fija su ubicación en el mapa interactivo (Leaflet + OSM). El sistema valida que la dirección esté dentro del radio de cobertura de 3 km usando la fórmula Haversine. El admin asigna un repartidor ejecutando el algoritmo ACO para calcular la ruta óptima. Los estados posibles son: sin_asignar → asignado → en_camino → entregado (o cancelado).

Usuario Sistema

Dos flujos independientes. Login: verificación de estado activo, comparación de contraseña con hash bcryptjs, mapeo de rol (customer / driver / admin) y emisión de JWT HS256 con TTL de 8 horas. Registro: validación de campos, unicidad de email y INSERT con idRole = 3 (Cliente) forzado en el backend — nunca se acepta el valor enviado por el cliente. Ambos flujos registran eventos en AKR_Auditoria.

Administrador Sistema · Motor ACO

Detalle técnico del Ant Colony Optimization (ACO) aplicado a la optimización de rutas de entrega. Los parámetros claves son: α (importancia de feromonas), β (importancia de la heurística), ρ (tasa de evaporación) y Q (constante de depósito). Las distancias entre nodos se calculan con Haversine en kilómetros. El ciclo de iteración continúa hasta alcanzar la convergencia o el número máximo de iteraciones.
